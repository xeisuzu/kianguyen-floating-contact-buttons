# Kianguyen Floating Contact Buttons

Floating contact buttons for WordPress: call, Zalo, Messenger, WhatsApp, Viber, Telegram, Facebook, TikTok, YouTube, Instagram, email, SMS and map directions — with full-color logos, grouping, working hours, page-specific button sets and Google Tag Manager click tracking.

Nút liên hệ nổi cho WordPress (Gọi, Zalo, Messenger, WhatsApp, Viber, Telegram, Email, SMS, Chỉ đường...), có giao diện tiếng Việt.

## Download

Install from the WordPress plugin directory: **[wordpress.org/plugins/kianguyen-floating-contact-buttons](https://wordpress.org/plugins/kianguyen-floating-contact-buttons/)** (Plugins → Add New → search "Kianguyen Floating Contact Buttons"), or download the ZIP from [Releases](https://github.com/xeisuzu/kianguyen-floating-contact-buttons/releases).

## Features

- Full-color app-style logos, white logos, simple icons or your own uploaded image
- Group buttons into one "Contact us" button; horizontal bottom bar on phones with a raised featured button
- Desktop call box with "Copy number" instead of a `tel:` link
- Weekly working hours (per day) and page-specific button sets
- Pre-filled messages for WhatsApp, SMS and email with `{title}` / `{url}`
- `dataLayer` click events for GTM (optional `gtag()`)
- No external requests, no jQuery on the front end, cache friendly (LiteSpeed Cache, WP Rocket...)
- Phone / Computer switch on the settings page: separate position, distance, size, spacing and grouping for each device, with a live preview you can hide
- Export / import settings
- Built-in Vietnamese interface (Settings → Contact Buttons → Display language)

## Installation

1. Install it from Plugins → Add New, or upload `kianguyen-floating-contact-buttons.zip` from [Releases](https://github.com/xeisuzu/kianguyen-floating-contact-buttons/releases) via Plugins → Add New → Upload Plugin.
2. Activate the plugin.
3. Go to **Settings → Contact Buttons**.

Requires WordPress 5.5+ and PHP 7.4+ (tested up to WordPress 7.1). See [readme.txt](readme.txt) for the full description, FAQ and changelog.
